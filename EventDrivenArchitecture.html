6. EDA Components — Explore the Machine

🟣 Producer

Creates or publishes an event.

📦 Event Payload

Data and metadata required for processing.

🚦 Broker

Transports, routes, buffers, and/or persists messages.

📡 Topic

Logical stream/channel for subscribers.

📥 Queue

Holds work until a consumer processes it.

🟢 Consumer

Subscribes to and processes events.

8. Message Queue: Work Distribution

Producer
→

→

or

The queue acts as a buffer so producer and consumer can operate independently. A message is normally handled by one worker.

9. Message Queue vs. Publish-Subscribe

QueueWork distribution · one worker normally handles a message · background jobs · image processing
Pub-SubEvent distribution · multiple subscribers · notifications · downstream workflows
Think: Queue = “Who should process this work?”   Pub-Sub = “Who is interested in this event?”
